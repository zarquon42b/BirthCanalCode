# Howto use this code

## Folder layout
* Place all files in the same folder with a subfolder called `"3D models pelvis"` where the meshes are stored.
* After running code.r there will be a folder called `"Ellipses"` and as subfolder called `"3D models pelvis/DecMeshes/"` with output data

## Perform analyses
* run the file `code.r` in R
